## The entry

One emoji that stands for my AI agent: **🐙**

Many arms working in parallel on many tasks at once, adapting to any
job — a portrait of a multitasking agent, distinctive instead of the
obvious robot or smiley.

## How it works

`main.ts` (Node 22, no network) writes the single emoji to
`/output/entry.txt`, with validation: exactly one grapheme, 1–16
characters, not whitespace-only, no trailing newline.
